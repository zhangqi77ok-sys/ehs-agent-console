# Day3 · 第一次开 Agent

> 今天目标：让 AI 助手答一句，并**看见它一步步干活**，不是只吐一段话。  
> 半小时。做完就停。

角色先改回 **EHS 工程师（可写）**。

---

## 步骤

1. 顶栏点 **Agent**。  
2. 输入框写：`有哪些未闭环隐患？`  
3. 点发送。  
4. **盯右边（或下方）的步骤列表**：会一条条出现——想做什么、调了什么工具、工具回了什么。  
5. 左边会出现助手的回答。你对照一下：它说的隐患，和 Domain 台账里是否对得上。  
6. （可选）再问一句：`查制度：灭火器`——若有资料，它会先搜再答。

今天**不要**急着让它开整改单；开单涉及「先同意」那一套，留给 Day5。

---

> **今天带走的一句话：**  
> AI 是操作员；真正的规矩还在台账那一套。

---

## 卡住了怎么办

- 一直转圈没步骤 → 看后端窗口还在不在；报错原文贴出来。  
- 回答很空 → 先用 Day1 造几条未闭环隐患，再问。  
- 英文报错看不懂 → 整段复制即可，不用自己翻译。
