# Day4 · 看步骤（人话版）

> 今天目标：再跑一轮 Agent，**把右边每一步用自己的话念出来**。  
> 不背名词。半小时。

---

## 步骤

1. 打开 **Agent** 页，再问一次：`有哪些未闭环隐患？`（或换个问题：`隐患 HZ-xxx 是什么状态？`——把 xxx 换成你列表里真有的编号）。  
2. 步骤刷出来后，对着屏幕用嘴说三遍（可以小声）：  
   - 「这一步是它在**决定**要不要动手」  
   - 「这一步是它**伸手去查/改**」  
   - 「这一步是**手里拿到的结果**」  
3. 注意：步骤是**一条条冒出来**的，不是等全部做完才突然整屏出现——这样你才知道它卡在哪。  
4. （可选）打开 **Runtime** 页瞄一眼：这里以后能看「暂停 / 续跑 / 审批」；今天只需知道「跑过的任务会留在这儿」。

---

> **今天带走的一句话：**  
> 步骤一条条推过来，是为了让你看见它卡在哪，而不是傻等。

---

## 卡住了怎么办

- 步骤闪一下就没了 → 再发一次同样的问题；或到 Runtime 里点开最近一条看详情。  
- 完全看不懂英文工具名 → 没关系，只记「查」还是「改」两种。  
- 页面卡死 → 刷新；两个终端窗口还在就行。
