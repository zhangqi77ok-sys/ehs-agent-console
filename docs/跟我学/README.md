# 跟我学（保姆级 · 一次只一天）

> 写给你：容易看懵、三分热度、希望有人一步步带着点。  
> **别一次学完。** 今天打开哪一天，就只做那一天。做完打勾就停。

## 这是什么

一个**工厂安全整改小软件**：网页上管隐患和整改单；旁边有个 AI 助手，也能查、也能帮开单——但**改数据必须遵守同一套规矩**。

你不是在背黑话，你是在亲手摸一遍：**怎样做出一个敢上线的小系统。**

## 怎么对抗三分热度

1. 日历只写「今天的那一天」——做完打勾就关文档。  
2. 每天只带走**一句话**（文件里的引用块）。  
3. 卡住立刻停，把屏幕现象或报错原文发出来，别硬啃后面。
