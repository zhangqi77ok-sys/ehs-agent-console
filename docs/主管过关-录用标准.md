## 本轮刚补上的（对主管更硬）

这些是之前主管会扣分、现在能指代码的点。名字要说诚实：

1. **企业登录前的自建 JWT 续期**（不是 Okta / 完整 OIDC）  
   - `POST /auth/token` 同时给 `access_token` + `refresh_token`  
   - `POST /auth/refresh` 换新 access（并轮换 refresh）  
   - `POST /auth/logout` 作废 refresh（内存 jti 黑名单，作品集级）  
   - 代码：`backend/app/auth/jwt_tokens.py`、`refresh_store.py`、`api/auth.py`

2. **W3C `traceparent`**  
   - 有入站头就续同一 `trace_id`；没有就生成  
   - 响应回写 `traceparent`，并继续回写 `X-Request-Id`  
   - access log 里带 `trace_id`  
   - 代码：`backend/app/middleware/observability.py`

3. **RAG 按租户过滤**  
   - 制度块带 `tenant_id`；工具检索只回本租户  
   - `demo-plant` 用公共制度；`tenant-other-plant/` 演示隔离  
   - 代码：`rag/store.py`、`rag/chunk.py`、`tools/domain_tools.py`

4. **主管过关门禁**  
   - `backend/tests/test_hire_gate.py` —— 关键路径一破 CI 就红

## 仍然关不上的（主动说加分）

| 关不上 | 为啥 | 面试怎么讲 |
|--------|------|------------|
| 真企业 IdP / SSO | 要连公司授权服务器、组织架构、会话策略 | 「本仓是自建 JWT 续期 + 可选 JWKS 验签；上线换成你们的登录。」 |
| 真连 Tempo / 全链路平台 | 要公司观测栈账号与采样策略 | 「已有 W3C traceparent + request_id + OTLP 开关；接 Tempo 是配置事。」 |
| 真人口语 / 临场 | 仓库测不了嘴 | 「技术点在仓里；录用看我现场能不能讲顺。」 |
| 和对方业务对口 | EHS 只是场景壳 | 「把关单证据 / 审批 / 评测换成你们领域一句话。」 |

## 你怎么用这份清单

1. 跑通 `pytest -q tests/test_hire_gate.py`（应全绿）。  
2. 按 [就业过关 · 最终版](./就业过关-最终版.md) 把 10 分钟演示练到不看稿。  
3. 面试主动说边界：续期不是完整 SSO；traceparent 不是已经接好 Tempo。  
4. **不要**对外说「保证录用」——那是撒谎，主管一听就否。

带走三句：

1. 关单要证据、访客写不了——人和 AI 同一套规矩。  
2. 登录能续能登出、请求能带上 trace、制度按厂隔离——能指代码。  
3. 过关是技术门槛；录用还要靠你讲清楚、对上业务。
