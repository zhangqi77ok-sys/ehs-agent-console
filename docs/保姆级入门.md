# 保姆级入门（大白话 · 一次只做一件事）

> 写给你：看文档容易懵、三分热度、希望有人一步步带着走。  
> **别一次学完。** 今天只做「第一天」。做完有成就感再说明天。

---

## 你先建立这个画面（30 秒）

把项目想成一个**工厂安全整改小软件**：

1. 网页上有一张「隐患清单」（哪里不安全）。  
2. 可以给隐患开「整改单」（谁去修、怎么修）。  
3. 修完要写「验收说明」才能关掉——没写就关不了。  
4. 旁边还有个「AI 助手」：它可以帮你查、帮你开单，但**真改数据时也要遵守上面的规矩**。

你不是在学一堆黑话，你是在学：**怎么做出一个敢上线的小系统**。

---

## 开始前：电脑上要能打开网页

### Windows（你常用的）

打开两个 PowerShell 窗口。

**窗口 A（后端 = 服务员）：**

```powershell
cd <你的仓库路径>\ehs-agent-console\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:LLM_PROVIDER="mock"
uvicorn app.main:app --reload --port 8000
```

看到类似 `Uvicorn running on http://127.0.0.1:8000` 就对了。**这个窗口不要关。**

**窗口 B（前端 = 网页）：**

```powershell
cd <你的仓库路径>\ehs-agent-console\frontend
npm install
npm run dev
```

浏览器打开：**http://127.0.0.1:5173**

卡住了？常见就三件事：端口被占用、没进对文件夹、没激活 `.venv`。把报错原文复制给我（私聊），我帮你看。

# 第一天（只要 20～30 分钟）

目标：**亲手点一次「正规关单」和一次「关不了」。**  
学会这两个，你就懂了项目一半灵魂。

## 步骤 1：打开「领域」页

顶栏找到 **领域**（或 Domain）——这是**人自己点按钮**改台账的地方，先别管 AI。

顶部有「租户」「角色」：

- 角色先选 **ehs_engineer**（工程师，可以写）  
- 租户保持 **default**

## 步骤 2：选一条隐患

左边列表点一条，比如灭火器相关的。  
右边会出现详情。

你心里只记一句：

> **隐患 = 问题；整改单 = 怎么修的任务单。**

## 步骤 3：开一张整改单

找到「开整改单」之类的按钮：

- 措施随便写：`更换过期灭火器并点检`  
- 提交

成功后，这条隐患下面应该出现一张整改单，状态大概是 **待执行**。

## 步骤 4：按顺序点推进（跟玩游戏升级一样）

按按钮顺序点（名字可能略有不同，意思对上就行）：

1. **开始** → 变成「执行中」  
2. **提交验收** → 变成「待验收」  
3. **关闭** → 这时会要你填「验收说明 / 证据」

**先故意留空点关闭** → 应该失败（网页报错或提示要证据）。  
**再填写一句** `已更换并拍照点检` → 关闭成功 → 隐患变成「已闭环」。

### 今天你要带走的唯一知识点

> **没有验收说明，系统不允许假装修完。**  
> 这就是工业里最疼的点之一：「假闭环」。

# 第二天（有空再来，也只要半小时）

目标：感受「权限」。

1. 顶栏角色改成 **viewer**（访客，只能看）。  
2. 再试「开整改单」或「推进」。  
3. 应该被拒绝。

带走一句：

> **不是谁都能改；改了还要留下审计记录。**  
> 面试官问「多租户 / 权限」时，你就讲：我点过 viewer 写不进去。

（审计列表在领域页下面或抽屉里，有空点开瞄一眼「谁、做了什么」。）

---

# 第三天：第一次碰 AI（仍然半小时）

目标：看 AI「一步步干活」，不是只吐一句答。

1. 角色改回 **ehs_engineer**。  
2. 打开 **Agent** 页。  
3. 输入：`有哪些未闭环隐患？`  
4. 发送。  
5. **盯右边步骤**：会看到它在调工具、出结果——这叫「Agent 循环」。

带走一句：

> **AI 是操作员；真正的规矩还在领域台账那一套。**

想再玩一个：输入 `查制度：灭火器`（如果有 RAG），看它是不是先搜文档再回答。

# 黑话翻译（只在你撞到时查）

| 你看到的词 | 人话 |
|------------|------|
| Agent | 会按步骤调用工具的 AI 助手 |
| 工具 / Tool | AI 的手：查清单、开单…… |
| SSE | 步骤一条条推到网页，不用傻等 |
| HITL | 重要操作先让人点「同意」 |
| Trace | 事后回放：它当时调了啥 |
| RAG | 先查资料再回答，少瞎编 |
| Eval | 用固定题目自动考系统有没有退步 |
| JWT | 登录后发的通行证 |
