# Eng-04 · 成都 20–30K 简历项目表述（工程补强④）

## 做了什么

把仓库真实能力收成可粘贴的简历段落与面试口述稿：

- 正文：[`docs/resume-project.md`](../resume-project.md)
- 同步更新：[`docs/interview.md`](../interview.md)、[`docs/curriculum.md`](../curriculum.md)

## 怎么用

1. 从 `resume-project.md` 复制「一句话 + 项目描述」进简历（按版面删到 5 条左右）。  
2. 面试前过一遍「30 秒版」和 `interview.md` 追问表。  
3. Demo 仍按 interview 里的 5 分钟剧本；权限 demo 优先展示 **API Key / JWT**（Eng-03），不要只靠改请求头。

## 验收清单（Definition of Done）

- [ ] 简历表述只写仓库里有的能力（含持久化 / pytest / request_id / JWT·API Key）  
- [ ] 有一句话标题、条列描述、技术栈、诚实量化口径  
- [ ] 与 `interview.md` 不互相打架  
- [ ] 课记在 `docs/lessons/eng-04-resume.md` 并已 push  

四条工程补强至此收口。后续按 JD 缺口再开专题即可。
