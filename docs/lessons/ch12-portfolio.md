## 面试官追问（≥5）

**Q1：作品集怎么讲才不像简历注水？**  
A：每个 bullet 能指到路径 + 30 秒 Demo。用 `jd-gap-matrix.md` 对齐 JD 关键词。

**Q2：10 分钟不够怎么办？**  
A：砍 Memory/Compose 细节，保：领域证据关单 → Agent 工具不旁路 → HITL → 多 Agent 双时间线 → 主动说差距。

**Q3：如何体现 90% 把握？**  
A：诚实：仓库无法保证 offer。能保证的是：高频追问有标准答、失败演练可现场做、代码非 stub。剩余风险在口语、真 LLM、公司匹配。

**Q4：简历 STAR 里 Result 怎么写？**  
A：能量化写测例数/章节 DoD/「mock 全链路 CI」；不写虚假 DAU。

**Q5：对方业务不是 EHS？**  
A：迁移点：状态机+审计+工具沙箱+HITL+Eval 是通用 Agent 应用后端模式；域可换工单/运维/客服。
