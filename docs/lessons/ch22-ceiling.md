## 核心口径（对用户 / 面试官）

- 本仓目标：把 **Agent 应用岗高频技术追问** 压到「能 demo + 能指代码 + 能说清差距」。
- **不能**、也**不会**写「保证 offer / 90% 过面」——口语、匹配度、对手盘、行为面不在仓库里。
- Ch18–21 关闭了矩阵里原先标注的 OTLP / JWKS / 并行 Multi-Agent / live eval 开关等残留；仍未覆盖的见 scorecard「红灯」。
