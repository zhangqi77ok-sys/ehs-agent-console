# Ch17 课记：面试练习模式

## 交付

- 前端 **Practice** Tab：加载 `practice-questions.json`
- 三档评分：完整 / 能答 / 不会 → `localStorage`
- `docs/practice-rubric.md` 评分说明
- 更新 `oral-15min.md`、`jd-gap-matrix.md` 残留项

## 怎么用

1. 闭卷练 8–10 题，每题 90 秒
2. 对照 rubric 自评
3. 「不会」清零后再约面

## 面试官追问（≥5）

**Q1：练习分能代表通过率吗？**  
A：不能。只降低技术追问空白；offer 仍看匹配与临场。

**Q2：题库从哪来？**  
A：压缩自 `mock-interview.md` + Ch13–16 新点（obs/MCP/多维 eval）。

**Q3：为何本地存分？**  
A：隐私；作品集不收集候选人数据。

**Q4：和 oral-15min 怎么配合？**  
A：oral 是连贯叙事；Practice 是单点追问火力网。

**Q5：还缺什么练习？**  
A：真人口述录音、系统设计白板、真 LLM 现场翻车演练——需你本人完成。

**Q6：残留技术风险？**  
A：见 jd-gap-matrix「仍未覆盖」：OIDC、OTel 全链路、生产 ANN、并行图编排。
