## 学习目标

1. 用 **本仓库真实能力** 讲清 30 秒故事，不堆框架名。
2. 对着 [interview.md](../interview.md) 练：架构一句话、手写循环 vs 框架、SSE、工具、超时重试、评测门禁。
3. 能独立走一遍 3–5 分钟 Demo 剧本，并回答 3 个 JD 追问。
4. 分清「已做 / 未做」，避免面试吹过头。

## 改了什么 / 为什么

本课 **几乎没有新业务代码**：交付物是面试资产。

| 文件 | 作用 |
|------|------|
| `docs/interview.md` | 完整中文讲法：故事、架构、Q&A、Demo、简历一行 |
| `docs/lessons/07-interview.md` | 本课：怎么练、练什么 |
| `README.md` | 挂上面试文档入口与 Week1 收官 |

**为什么单独一天：** 很多作品集「代码有了、嘴上讲不清」。Day7 强迫你把 Runtime / 可观测 / 门禁收成可背诵结构。

## 跟练（建议 60–90 分钟）

### 1. 精读

打开 [docs/interview.md](../interview.md)，先读 §1–§3 与 §7，再扫 §9 追问。

### 2. 对着控制台练口述

```bash
# 后端 + 前端按 README 拉起后
# 按 interview.md §8 Demo 剧本走一遍，边点边说
```

强制自己说出这四句：

1. 「模型负责想，Runtime 负责稳」  
2. 「SSE 边跑边推，不是整轮再吐」  
3. 「步数预算是熔断，不是装饰」  
4. 「评测脚本和 UI 走同一条 run_agent」

### 3. 默写架构

合上文档，在纸上画出 §2 的 ASCII；缺一块就回去补读对应课记（01/03/05）。

### 4. 模拟追问（选 3 个）

从 interview.md §9 抽问，计时 60 秒内答完；答不出就回到对应代码文件指一行。

### 5. 简历一行

把 §10 那一行改成你自己的口吻，贴进简历「项目经历」。

## 思考题

1. 若面试官说「我们只用 LangGraph」，你如何 20 秒迁移本项目经验？  
2. 评测 5 条够不够？你会如何向面试官解释「小而真」？  
3. 指出一个你 **故意没做** 的能力，并说明为什么 Week1 不做是对的。
