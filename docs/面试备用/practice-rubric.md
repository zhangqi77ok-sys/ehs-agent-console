# 面试练习评分标准（Ch17）

> ⚠️ **先别看这份——跟完 [docs/跟我学](../跟我学/README.md) 再来。**


对本仓 **Practice** 页每道题，按三档自评（写入浏览器 localStorage，不上传）：

| 档位 | 含义 | 建议 |
|------|------|------|
| **完整** | 能指路径 + 讲清边界/失败态 + 30 秒 Demo 步骤 | 可上正式面 |
| **能答** | 能说清概念，但路径或失败态卡顿 | 对照课记再练 1 遍 |
| **不会** | 概念混乱或空白 | 先读对应 lesson，再闭卷重答 |

## 建议节奏

1. 闭卷抽 8–10 题（覆盖 Runtime / HITL / Eval / RAG / ACL）
2. 每题限时 90 秒口述
3. 对照 `docs/mock-interview.md` 与课记打分
4. 「不会」清零后再约真面

## 诚实边界

练习分 **≠** offer 概率。它只缩小「技术追问答不上」的风险；公司匹配、口语临场、真 LLM 体验仍是外部变量。
