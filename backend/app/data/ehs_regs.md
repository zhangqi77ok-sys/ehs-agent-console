# EHS 制度与法规摘要（教学演示用，非正式法律文本）

## 双重预防机制
- 企业应建立安全风险分级管控和隐患排查治理双重预防工作机制。
- 风险分级管控：对风险点辨识、评价，按重大/较大/一般/低确定管控层级与措施。
- 隐患排查治理：与风险管控清单对应，明确排查周期、责任人、闭环时限。
- 重大风险场所应设置明显警示，并提高排查频次。

## 隐患分级
- **重大隐患**：可能导致死亡或重大财产损失，须立即停工、撤人并上报单位负责人及属地监管要求的渠道。
- **一般隐患**：可能导致轻伤或一般财产损失，须在规定期限内整改并复查。
- 分级由现场安全员初判，EHS 部门复核；重大隐患须当日通知单位主要负责人。
- 电气裸露带电、有限空间无票作业、危化品账实严重不符等，原则上按重大隐患管控。

## 闭环要求
1. 发现隐患后 **24 小时内**登记台账，明确责任人、措施与整改期限。
2. 一般隐患整改期限原则上不超过 **7 个工作日**；重大隐患须制定专项方案并报批，必要时停产停业整顿。
3. 整改完成后须 **复查验收**，形成闭环记录；未通过复查的不得销号。
4. 超期未整改的隐患应升级通报，纳入绩效考核，必要时按重大隐患提级管理。
5. 整改单状态建议：待执行 → 执行中 → 待验收 → 已关闭；与台账状态（待整改/整改中/待验收/已闭环）联动。

## 作业票
高处作业、有限空间、动火作业须办理作业票，并落实监护人。
作业前须进行危害辨识与交底；气体检测不合格不得进入有限空间。
动火监护人不得离岗；中断超过规定时间须重新审批作业票。
作业票、检测记录、监护记录应与隐患/检修工单可追溯关联。

## 危化与消防
危化品储存实行双人双锁、台账与实物一致；领用须签字。
气瓶应固定防倾倒，氧气与乙炔间距符合要求。
灭火器、应急照明、疏散指示须定期点检；过期或失效器材立即更换。
疏散通道、安全出口严禁堆放物料。

## 台账与记录
隐患台账至少保存 3 年，内容包括：编号、位置、类别、级别、发现人、整改措施、验收人、闭环时间。
电子台账与纸质记录应一致；抽查时须能追溯到当日现场照片或检测报告。
重大隐患治理情况应按要求向监管部门报告（演示环境仅保留字段与流程，不模拟真实报送）。

## 培训与应急
新入职及转岗人员上岗前须完成 EHS 培训；特种作业人员持证上岗。
应急预案每年至少演练一次；消防器材与应急照明定期点检并记录。
